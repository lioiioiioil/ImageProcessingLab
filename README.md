# 🔬 ImageProcessingLab

Шесть программ на C++ для изучения цифровой обработки изображений: от гистограмм и FFT до морфологии и анализа связных областей.

![C++](https://img.shields.io/badge/C++-17-00599C?logo=cplusplus&logoColor=white)
![OpenCV](https://img.shields.io/badge/OpenCV-4-5C3EE8?logo=opencv&logoColor=white)

## Алгоритмы

| Программа | Что реализовано |
|---|---|
| `lab1` | Гистограммы, гауссов шум, матрица совместной встречаемости яркостей |
| `lab2` | Одномерное и двумерное FFT, визуализация амплитудного спектра |
| `lab3` | Поворот с интерполяцией: ближайший сосед, билинейная, бикубическая |
| `lab4` | Свёртки, шум, усреднение с порогом, Лапласиан/LoG, резкость и границы |
| `lab5` | Ранговые фильтры, усечённое среднее, морфология, сравнение по PSNR |
| `lab6` | Порог Оцу, 4-связные компоненты, моменты и поиск округлых областей |

Основные алгоритмы написаны вручную; OpenCV предоставляет матрицы, чтение и запись изображений и вспомогательные операции.

## Сборка

Нужны компилятор C++17, CMake ≥ 3.16 и OpenCV 4 с заголовками для C++. Python-пакет `opencv-python` не заменяет эту зависимость.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Если OpenCV установлен в нестандартный каталог, передайте `-DOpenCV_DIR=/path/to/lib/cmake/opencv4` при конфигурации.

## Демонстрация

В `examples/` включены небольшие синтетические изображения. Они не содержат фотографий или личных данных. Скрипт копирует их в отдельную рабочую папку и запускает выбранную программу:

```bash
python3 scripts/run_demo.py lab6
python3 scripts/run_demo.py lab2
```

Результаты появятся в `runs/lab6/` и `runs/lab2/`. Для другой конфигурации сборки можно указать `--binary build/Release/lab6.exe`. Исходные программы используют фиксированные имена `1.png`–`4.png` или `1.jpg`–`4.jpg`; запускайте их из каталога, где лежат эти файлы.

Для пересоздания демонстрационных данных:

```bash
python3 -m pip install -r requirements-demo.txt
python3 scripts/generate_examples.py
```

## Структура и ограничения

- `src/lab1.cpp`–`src/lab6.cpp` — исходные программы.
- `examples/` — синтетические входные данные.
- `scripts/` — подготовка и запуск демонстраций.

Программы запускаются отдельно. Это учебные реализации с фиксированными параметрами; обработка отсутствующих файлов неодинакова, поэтому для первого запуска используйте `run_demo.py`. Измерения времени и шум могут отличаться между запусками. Демо подтверждает запуск, но не доказывает точность алгоритмов на произвольных изображениях.

## Установка зависимостей C++

Для Ubuntu/Debian:

```bash
sudo apt install build-essential cmake libopencv-dev
```

Для macOS с Homebrew:

```bash
brew install cmake opencv
```
